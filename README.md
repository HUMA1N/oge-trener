# oge-trener

Тренажёр для подготовки к ОГЭ по математике: задания **1–19** (первая часть) и **20–22** (вторая часть).
Сайт статический (HTML/CSS/JS, без сервера и без зависимостей), удобен с телефона,
устанавливается как приложение и работает без интернета.

**Открыть онлайн:** https://huma1n.github.io/oge-trener/ (после включения GitHub Pages, см. ниже).

## Возможности

- **Генератор задач.** При каждом запуске — новые числа. Все 19 номеров первой части:

  | № | Тема | Разновидности |
  |---|------|---------------|
  | 1–5 | Практико-ориентированные задачи с общим условием | сюжеты «Шины», «Листы бумаги», «План участка» (план рисуется, объекты нумеруются заново) |
  | 6 | Вычисления | обыкновенные и десятичные дроби, «многоэтажные» дроби, степени (−10)ⁿ |
  | 7 | Числа на координатной прямой | какая точка соответствует √N или p/q, какое число отмечено, верные утверждения про a и b |
  | 8 | Степени и корни | √a·√b, (k√t)², разность квадратов, √(pⁿ·qᵐ), свойства степеней, a·10ⁿ |
  | 9 | Уравнения | линейные, со скобками, пропорции, квадратные (больший/меньший корень), неполные, (x+p)² = (x+q)² |
  | 10 | Теория вероятностей | классическая вероятность, брак, жеребьёвка, противоположные события, монеты, кубики |
  | 11 | Графики функций | знаки k и b, знаки a и c, графики ↔ формулы (прямая, парабола, гипербола, корень) |
  | 12 | Расчёты по формулам | 10 формул из физики, экономики и геометрии; неизвестной может быть любая величина |
  | 13 | Неравенства | линейные, квадратные, системы, «нет решений / любое число»; варианты — рисунки на прямой |
  | 14 | Прогрессии | ряды кинозала, тренировки, камень, улитка, распад изотопа, бактерии, схема приёма лекарства |
  | 15 | Треугольники | Пифагор, углы, биссектриса, медиана, sin/cos/tg, площади, средняя линия, равносторонний |
  | 16 | Окружность | вписанный и центральный углы, дуги, диаметр, касательные, хорда, описанная окружность |
  | 17 | Четырёхугольники | параллелограмм, ромб, прямоугольник, квадрат, трапеция (углы, площади, средняя линия) |
  | 18 | Клетчатая бумага | площади фигур, средняя линия, расстояние до прямой, тангенс угла |
  | 19 | Геометрические утверждения | банк из 80 утверждений + утверждения с числами (существует ли треугольник и т. п.) |
  | 20 | Уравнения, неравенства, системы | биквадратные, разложение группировкой, с корнем и ОДЗ, замена 1/x, дробные с посторонним корнем, системы «парабола + прямая», неравенства (x−a)² < k(x−a) и x²(−x²−n) ≤ n(−x²−n) |
  | 21 | Текстовые задачи | движение по реке (в т. ч. со стоянкой), трубы и велосипедисты, совместная работа, смеси, средняя скорость, поезд и пешеход |
  | 22 | Графики с параметром | дробь с выколотыми точками и y = m, функции с модулем x·|x|, парабола с выколотой точкой и прямая y = kx (касание) |

- **Вторая часть (20–22).** На экзамене эти задания решаются с полной записью, а в тренажёре вводится
  итоговый ответ: корни через точку с запятой (`−2; 3`, порядок не важен, можно `1/3`), решения системы
  парами (`(1; 2), (−3; 4)`), значения параметра. Для неравенств — выбор верного промежутка.
  Разбор показывает решение так, как его оформляют в бланке: ОДЗ, замена, дискриминант, отбор корней,
  таблица «скорость — время — расстояние», построенный график с выколотыми точками и прямыми.
  На телефоне под полем ответа есть кнопки «;», «−», «/», «(», «)».

- **Мгновенная проверка.** Ответ можно писать через запятую или точку, «−» и «-» одинаковы, а кнопка «±» на телефоне ставит минус. Запись вроде «1/4» не засчитывается как ошибка — тренажёр напомнит, что в бланк пишут десятичную дробь.
- **Пошаговый разбор** появляется при ошибке (и по кнопке «Не знаю»). После верного ответа разбор можно открыть по желанию.
- **Режим «Тренировка по номеру задания»** и режим **«Слабые места»**: задания с большой долей ошибок попадаются чаще.
- **Режим «Работа над ошибками».** Каждая ошибка (в тренировке или в варианте, в том числе «Не знаю»)
  добавляет в список *тип* задания — номер и разновидность (например, «№ 9, квадратное уравнение»).
  В этом режиме повторяются только такие типы, с новыми числами. Тип уходит из списка, когда решён
  **3 раза подряд верно**; ошибка сбрасывает серию. Прогресс виден кружками на главной, на странице
  статистики и над задачей.
- **Установка на телефон (PWA).** Значок на главном экране, открывается без адресной строки, после первого
  открытия работает полностью без интернета (все файлы сохраняются при установке). Инструкция для Android,
  iPhone и компьютера — на странице «Установить на телефон» (ссылка внизу сайта).
- **Режим «Полный вариант на время»** (45/60/90/120 мин): 19 заданий, таймер, ответы сохраняются при перезагрузке, при окончании времени вариант завершается сам. Результат — первичный балл, отметка по шкале ФИПИ (с условием «не менее 2 баллов по геометрии»), разбор каждого задания.
- **Статистика** (включая список ошибок) хранится в браузере (`localStorage`): доля ошибок по каждому номеру за последние 20 попыток в виде графика, порог «нужно подтянуть», список того, что подтянуть в первую очередь, график баллов за пробные варианты.

## Как открыть (для новичка, Windows)

**Способ 1 — по ссылке (удобнее всего, нужен для телефона).**
Откройте https://huma1n.github.io/oge-trener/ в браузере. На телефоне: меню браузера →
«Установить приложение» / «Добавить на главный экран» (на iPhone в Safari: «Поделиться» → «На экран „Домой“»).

**Способ 2 — с компьютера без интернета.**
1. На странице репозитория нажмите зелёную кнопку **Code → Download ZIP**.
2. Распакуйте архив (правой кнопкой → «Извлечь всё…»).
3. Откройте папку и дважды щёлкните файл **index.html** — тренажёр откроется в браузере.
   Так всё работает, кроме установки как приложение (для неё нужна ссылка https://…).

## Публикация на GitHub Pages

Публикацию делает GitHub Actions (`.github/workflows/pages.yml`) при каждом изменении ветки `main`:
сначала прогоняются тесты, потом сайт выкладывается. Один раз нужно включить:
**Settings → Pages → Build and deployment → Source: «GitHub Actions»**.
После первого запуска сайт будет по адресу https://huma1n.github.io/oge-trener/.

## Локальный сервер для разработки

```sh
python3 -m http.server 8000   # или: npm start;  на Windows: py -m http.server 8000
# открыть http://localhost:8000
```

## Автотесты

```sh
npm test        # то же, что node --test (нужен Node.js 20+; зависимостей нет)
```

На Windows: установите Node.js (версия LTS) с https://nodejs.org, откройте папку проекта,
в адресной строке Проводника наберите `cmd` и нажмите Enter, затем введите `npm test`.

Тесты загружают те же файлы, что и страница (список берётся из `index.html`), и проверяют:

- **Правильность ответов независимым способом** (`tests/answers.test.js`, решатели — `tests/helpers/solvers.js`).
  Для каждой разновидности каждого задания генерируются задачи на множестве зёрен, и ответ
  пересчитывается не так, как в генераторе:
  - выражения (задания 6, 8) вычисляются обычной арифметикой JavaScript **по тексту формулы**,
    поэтому потерянные скобки в записи тоже будут пойманы;
  - уравнения (9) — восстановлением многочлена по значениям левой и правой частей и решением заново;
  - неравенства (13) — проверкой контрольных точек на прямой: решению должен соответствовать ровно один рисунок;
  - графики (11) — по точкам нарисованной линии определяются знаки коэффициентов / подходящая формула;
  - вероятности (10) — перебором исходов; прогрессии (14) — пошаговой симуляцией;
  - геометрия (15–18) — генератор строит настоящий чертёж в координатах, тест проверяет,
    что **все данные условия выполнены на чертеже**, и измеряет искомую величину (`tests/helpers/geometry.js`);
  - задания 1–5 — по исходным данным сюжета; для «Листов бумаги» используются настоящие размеры ISO 216,
    для плана участка проверяется согласованность текста и рисунка;
  - задание 19 — истинность утверждений с числами вычисляется заново;
  - задание 20 — корни ищутся численно по формуле из условия (сетка + деление пополам; точки вне ОДЗ
    и выколотые точки отбрасываются сами, потому что там формула не определена), неравенства — проверкой точек;
  - задание 21 — уравнение сюжета решается делением пополам или формулами Крамера, числа сверяются с текстом;
  - задание 22 — для каждого значения параметра из ответа численно считается число общих точек графика
    с прямой, а для соседних и других значений проверяется, что нужного числа точек нет.
- **Структуру задач** (`tests/tasks-structure.test.js`): одинаковое зерно → та же задача, разные зёрна → разные
  числа; ответ — конечная десятичная дробь или цифры; разбор заканчивается ответом; нет «NaN»/«undefined»;
  теги сбалансированы; верные варианты в заданиях 7 и 13 равномерно распределены по номерам.
- **Ядро** (`tests/core.test.js`): точные дроби, округление, форматирование и случайные выражения —
  запись на экране и вычисленное значение совпадают.
- **Проверку ответа**, **вариант и шкалу отметок**, **статистику** (`tests/check-answer.test.js`,
  `tests/variant-and-stats.test.js`), включая ответы второй части (списки корней, пары чисел).
- **Работу над ошибками** (`tests/review.test.js`): серия из 3 верных подряд, сброс при ошибке,
  выбор только типов с ошибками, перенос старой статистики, воспроизведение разновидности задачи.
- **Офлайн-режим и установку** (`tests/pwa.test.js`): каждый файл из `index.html` есть в списке кэша
  `sw.js`, у манифеста есть иконки 192/512 и маскируемая иконка нужных размеров.

Число проверяемых задач на разновидность можно увеличить: `OGE_SAMPLES=1000 npm test`.
Тесты запускаются в GitHub Actions (`.github/workflows/test.yml`) при каждом пуше в любую ветку и в каждом pull request, на Node 20 и 22.

## Устройство

```
index.html            страница и порядок подключения скриптов
css/style.css         стили (светлая и тёмная тема, мобильная вёрстка)
js/core/              rng (зерно), frac (точные дроби), format, expr (формулы),
                      draw (SVG-рисунки), geo (геометрия), answer (проверка ответа)
js/tasks/             генераторы: practice.js (1–5), t06.js … t19.js, registry.js
js/variant.js         полный вариант и шкала отметок
js/stats.js           статистика в localStorage
js/chart.js           графики статистики
js/app.js             интерфейс (маршруты #/train, #/variant, #/stats)
sw.js                 офлайн-режим (на http/https)
tests/                автотесты (node:test)
```

Каждый генератор по объекту `Rng` возвращает условие (HTML), ответ, шаги разбора и `data` —
исходные параметры, по которым тесты пересчитывают ответ. Чтобы добавить разновидность задания,
допишите её в соответствующий `js/tasks/tNN.js` и добавьте ветку в решатель `tests/helpers/solvers.js`
(тест упадёт, если разновидность не умеет проверяться).

Шкала перевода баллов — ФИПИ для ОГЭ по математике: «3» от 8 баллов (из них не менее 2 за геометрию),
«4» от 15, «5» от 22. В тренажёре только первая часть (максимум 19 баллов), поэтому «5» за неё получить нельзя.
